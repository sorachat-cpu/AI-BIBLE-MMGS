# assets/ — วัสดุที่ดาวน์โหลดมาเอง

โฟลเดอร์นี้เก็บของที่**ต้องโหลดจากภายนอก** ระบบอ่านจากที่นี่ ไม่มีการดาวน์โหลดอัตโนมัติ
เพราะทั้งสามแหล่งต้องกดยอมรับสัญญาอนุญาตด้วยตัวเอง และบางแหล่งจำกัดจำนวนต่อวัน

```
assets/
  fonts/      ฟอนต์ .ttf   → ติดตั้งเข้าเครื่องด้วย
  icons/      ไอคอน .svg   → Flaticon
  photos/     ภาพพื้นหลัง  → Pixabay
  video/      คลิปประกอบ   → Mixkit
  CREDITS.md  บันทึกที่มาของทุกไฟล์ (ดูหัวข้อ "เครดิต" ด้านล่าง)
```

---

## 1. ฟอนต์ — ทำก่อนอย่างอื่น เห็นผลทันที

ตอนนี้เครื่องมีฟอนต์ไทยแค่ 5 ตัวและเป็นของเก่าทั้งหมด (Sathu, Silom, Krungthep,
Ayuthaya, Sukhumvit Set) ระบบใช้ **Sukhumvit Set** อยู่ ซึ่งพอใช้ได้ แต่ยังไม่ใช่ตัวที่ดีที่สุด

### ตัวที่ควรติดตั้ง: **Prompt**

มินิมอล ทรงเรขาคณิต ดูสมัยใหม่ ไม่ดูแก่ มี 9 น้ำหนักให้เลือก
เป็นฟอนต์ที่งานการตลาดอสังหาฯ ไทยใช้กันมากที่สุดตัวหนึ่ง

```
https://fonts.google.com/specimen/Prompt
```

**วิธีติดตั้ง (macOS)**
1. กด **Get font** → **Download all** จะได้ไฟล์ zip
2. แตกไฟล์ แล้วเลือกน้ำหนักที่ใช้จริง: `Prompt-Regular.ttf` · `Prompt-Medium.ttf` ·
   `Prompt-SemiBold.ttf` · `Prompt-Bold.ttf` (ไม่ต้องลงครบ 18 ไฟล์)
3. คัดลอกไปไว้ที่ `assets/fonts/` **และ** ดับเบิลคลิกทีละไฟล์เพื่อติดตั้งเข้าเครื่อง
   (ต้องติดตั้งจริง เพราะตัวเรนเดอร์อ่านฟอนต์จากระบบ ไม่ได้อ่านจากโฟลเดอร์นี้)
4. รัน `npm run publish -- carousel:all` แล้วสไลด์จะเปลี่ยนฟอนต์เอง

> **ไม่ต้องแก้โค้ด** — `carousel-engine.mjs` ตั้ง font stack ไว้เป็น
> `Prompt → IBM Plex Sans Thai → Noto Sans Thai → Sukhumvit Set → Sathu`
> ตัวเรนเดอร์จะหยิบตัวแรกที่มีในเครื่องเอง

**ทางเลือกอื่น** ถ้าไม่ชอบ Prompt: `IBM Plex Sans Thai` (ทางการกว่า) · `Noto Sans Thai`
(กลางๆ) — ทั้งคู่อยู่ใน font stack แล้ว ลงตัวไหนก็ใช้ตัวนั้น
สัญญาอนุญาต **OFL ทั้งหมด ใช้เชิงพาณิชย์ได้ ไม่ต้องให้เครดิต**

## 2. ไอคอน — Flaticon

```
https://www.flaticon.com
```

- โหลดเป็น **SVG** เท่านั้น (PNG จะแตกเวลาขยาย)
- เลือกสไตล์ **linear / outline** เส้นบาง ให้เข้ากับโทนมินิมอลของสไลด์
- วางไว้ที่ `assets/icons/` ตั้งชื่อสื่อความหมาย เช่น `deed.svg` `road.svg` `water.svg`

> ⚠ **บัญชีฟรีของ Flaticon บังคับให้เครดิต** ถ้าไม่ใส่ถือว่าผิดสัญญาอนุญาต
> ต้องบันทึกลง `CREDITS.md` ทุกไฟล์ และแสดงเครดิตในโพสต์หรือในโปรไฟล์เพจ
> ถ้าไม่อยากยุ่งกับเครดิต ใช้ Pixabay แทนได้ (ไม่บังคับ)

---

## 3. ภาพ — Pixabay

```
https://pixabay.com
```

- ภาพวิว ท้องฟ้า ทุ่งนา พื้นผิวกระดาษ สำหรับเป็นพื้นหลังสไลด์
- ขนาดอย่างน้อย **1080 × 1350** (อัตราส่วนสไลด์)
- วางไว้ที่ `assets/photos/`
- **Pixabay Content License ไม่บังคับเครดิต** และใช้เชิงพาณิชย์ได้
  แต่ห้ามเอาไฟล์ต้นฉบับไปขายต่อแบบไม่ดัดแปลง

---

## 4. คลิป — Mixkit

```
https://mixkit.co/free-stock-video/
```

- คลิปสั้นประกอบ เช่น มุมสูงทุ่งนา แสงแดดลอดใบไม้
- วางไว้ที่ `assets/video/`
- **Mixkit Free License ไม่บังคับเครดิต** ใช้เชิงพาณิชย์ได้
  แต่ห้ามใช้คลิปที่มีคนเป็นตัวเอกไปโฆษณาในลักษณะรับรองสินค้า

---

## เครดิต — บันทึกทุกไฟล์ที่โหลดมา

ทุกครั้งที่เพิ่มไฟล์ ให้เพิ่มบรรทัดใน `assets/CREDITS.md` ด้วย รูปแบบ:

```
| ไฟล์ | แหล่ง | ผู้สร้าง | ลิงก์ | ต้องให้เครดิตไหม |
```

ทำเพราะสองเหตุผล: Flaticon บังคับเครดิตจริงและตรวจได้ · และถ้าวันหนึ่งต้องเปลี่ยน
ผู้ให้บริการหรือถูกทักท้วงเรื่องลิขสิทธิ์ จะรู้ทันทีว่าไฟล์ไหนมาจากไหน
โดยไม่ต้องไล่หาย้อนหลังทีละรูป
