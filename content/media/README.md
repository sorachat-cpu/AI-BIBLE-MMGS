# วางรูปที่จะใช้โพสต์ไว้ในโฟลเดอร์นี้

รองรับ `.jpg` `.jpeg` `.png` `.webp` — วางไฟล์ทิ้งไว้เฉยๆ ระบบจะเห็นเองในรอบถัดไป

ช่อง **08:00 (เช้า · ภาพ + แคปชั่น)** ในตารางดึงรูปจากที่นี่
ถ้าโฟลเดอร์นี้ว่าง ช่องเช้าจะไม่มีของลงและขึ้นว่า "คลังรูปว่าง"

## ใส่ข้อมูลให้รูปเพื่อให้แคปชั่นตรงขึ้น

ไม่ใส่ก็ได้ — ระบบจะใช้ค่าเริ่มต้นจาก `content/page.profile.json` แทน

```bash
npm run publish -- stock:tag "land-01.jpg" \
  --title "ที่ดิน 2 ไร่ องครักษ์" \
  --tags "ติดถนนลาดยาง,ถมแล้ว,ใกล้ตลาด 1 กม." \
  --price 2500000

npm run publish -- stock:retire "land-01.jpg"   # เลิกใช้ไฟล์นี้ในการหมุนเวียน
```

ดูของทั้งหมดในคลังด้วย `npm run publish -- stock`
