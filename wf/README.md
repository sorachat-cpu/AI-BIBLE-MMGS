> ถ้าโค้ดขัดกับไฟล์พวกนี้ ให้ยึดไฟล์พวกนี้แล้วแก้โค้ด ไม่ใช่แก้สเปคให้เข้ากับโค้ด
> บันทึกการทำจริง ข้อจำกัดที่เจอ และผลทดสอบ อยู่แยกที่ `../WF-IMPLEMENTATION-NOTES.md`

| ไฟล์ | เนื้อหา | จุดเชื่อม |
|---|---|---|
| [WF1.md](WF1.md) | Location Pin → Fast Zoom → ผ่านชั้นเมฆ → ภาพที่ดินจริง | FINAL FRAME = รูปที่ดิน input |
| [WF2.md](WF2.md) | ที่ดิน → Timelapse ก่อสร้าง → บ้านสวน 1 ชั้น ยามค่ำ | FINAL FRAME = บ้านเสร็จตอนค่ำ |
| [WF3.md](WF3.md) | บ้านยามค่ำ → Hero Shot → Pull Back → Advertisement | FINAL FRAME = เฟรมโฆษณา |

## หัวใจของทั้งระบบ

```text
FINAL FRAME  =  NEXT FIRST FRAME
```

ทั้ง 3 WF ต้องต่อกันด้วย **ภาพเดียวกัน** เพื่อให้เอามาต่อกันแล้วรู้สึกเป็นวิดีโอเดียว
**ห้ามใช้ Hard Cut ระหว่าง WF**

```text
WF1 ─── รูปที่ดินจริง ───► WF2 ─── บ้านเสร็จตอนค่ำ ───► WF3
```

## กฎที่ใช้ร่วมกันทุก WF

1. **ข้อมูลที่ไม่ได้ให้มา ห้ามสร้างขึ้นเอง** — ราคา ขนาดที่ดิน ระยะทาง จุดเด่น ต้องมาจาก input เท่านั้น
2. **ที่ดินคือค่าคงที่** — ภูมิประเทศ ถนน ภูเขา แนวต้นไม้ ต้องเหมือนเดิมทุก WF
3. **บ้านเป็นภาพจำลอง** — ต้องระบุว่าเป็น Concept Visualization ห้ามทำให้เข้าใจว่ามีบ้านจริง
4. **Mobile first** — output สุดท้ายเป็น 9:16
5. **ห้าม Hard Cut / ห้าม Fade ระหว่างจังหวะ** — ใช้การเคลื่อนกล้องเชื่อม

## ไฟล์พร้อมใช้สำหรับ Google Flow

อยู่ที่ `../output/flow/`

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `WF1_START_satellite.png` | start frame ของ WF1 (ดาวเทียมสะอาด ครอปลายน้ำแล้ว 9:16) |
| `WF1_END_land.png` | end frame ของ WF1 = รูปที่ดินจริง |
| `WF1-PROMPT.txt` | prompt + ขั้นตอนสำหรับ Flow |
| `WF2_START_land.png` | start frame ของ WF2 — **ไฟล์เดียวกับ `WF1_END_land.png`** |
| `WF2-PROMPT.txt` | prompt สร้างภาพบ้านตอนค่ำ + prompt วิดีโอ timelapse |

WF3 ไม่ต้องใช้ Flow — ระบบทำเองได้ด้วย `runWf3Ad()` ($0 ไม่ใช้ AI)

## สองทางเลือกในการสร้างคลิป

| | อัตโนมัติ (fal / Veo 3.1) | ทำมือ (Google Flow) |
|---|---|---|
| ต้องเปิด Flow ไหม | ไม่ต้อง | ต้อง |
| ต้องมีอะไร | `FAL_KEY` ใน `.env` | Google AI Plus |
| ค่าใช้จ่าย | ~$0.80/ทรัพย์ (2 คลิป · 1080p) | รวมใน subscription |
| ความยาวคลิป | 4 / 6 / 8 วิ | ยาวกว่าได้ |
| ปุ่มในหน้าเว็บ | "สร้างให้เลย" | "ทำต่อจากไฟล์ที่วางไว้" |

ทั้งสองทางใช้ prompt ชุดเดียวกัน (`TPL_WF1_v1`, `TPL_WF2_v1` ใน `prompt-library.mjs`)
และผ่านโค้ดปิดงานตัวเดียวกัน ผลลัพธ์จึงไม่แตกต่างกันเชิงโครงสร้าง

**ใส่รูปที่ดินรูปเดียวพอ** — ไม่ต้องเตรียมภาพบ้านล่วงหน้า
WF1 ใช้ endpoint แบบ 2 เฟรม (ต้องจบที่รูปที่ดินจริงตามกฎ) ส่วน WF2 ใช้แบบเฟรมเดียว
ปล่อยให้โมเดลสร้างบ้านระหว่าง timelapse แล้ว**ดึงเฟรมสุดท้ายของคลิปมาเป็นภาพบ้านเสร็จ**
ซึ่งกลายเป็นภาพหลักของ WF3 — จุดเชื่อมยังครบ แค่ได้มาจากการอ่านผลลัพธ์แทนการเตรียมล่วงหน้า

> **Google AI Plus ไม่ได้ให้สิทธิ์ API** — subscription นั้นใช้ Flow บนเว็บ ส่วนโหมดอัตโนมัติ
> ต้องมี `FAL_KEY` แยกต่างหาก จ่ายตามใช้

## พอได้คลิปจาก Flow แล้วรันอันเดียวจบ

```bash
node --env-file-if-exists=.env src/cli/wf-finish.mjs \
  --wf1 output/flow/WF1_result.mp4 \
  --wf2 output/flow/WF2_result.mp4 \
  --land output/flow/WF1_END_land.png \
  --house output/flow/WF2_END_house_night.png \
  --price 1590000 --size "1 ไร่ 2 งาน" \
  --title "บ้านสวนกลางธรรมชาติ" \
  --location "ต.หนองน้ำแดง อ.ปากช่อง จ.นครราชสีมา" \
  --contact "081-234-5678 · LINE @244raxjb" \
  --features "บ้านสวนชั้นเดียว,สวนธรรมชาติ,โรงจอดรถ,บรรยากาศสงบ"
```

ทำให้ครบ: ปักหมุด WF1 → freeze เฟรมสุดท้ายเป็นรูปจริง → freeze WF2 → สร้างโฆษณา WF3 → ต่อเป็นวิดีโอเดียว + caption

ส่งแค่บางส่วนก็ได้ (เช่นมีแต่ `--wf1`) ระบบจะทำเท่าที่มี · `--no-pin` ปิดหมุด · `--no-wf3` ข้ามโฆษณา
